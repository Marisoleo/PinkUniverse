# PinkUniverse – Starter-App

Eine responsive React-App mit pinkem Design, Dashboard, IdeaCloud, Planner, StudySpace, Move & Glow, Self-Care, Budget, Journal, Library, Rezepten, Outfits, Reisen, Watch & Read, Friends, Cozy World und Design-Themes.

## Starten

1. Installiere Node.js (LTS), falls es noch nicht installiert ist.
2. Öffne diesen Ordner in VS Code.
3. Öffne **Terminal → New Terminal**.
4. Führe aus:

```bash
npm install
npm run dev
```

5. Öffne die lokale URL, die Vite im Terminal ausgibt.

## Daten

Die App speichert Inhalte mit `localStorage` in diesem Browser auf diesem Gerät. Die Daten werden nicht automatisch auf andere Geräte übertragen. Unter Settings kannst du ein JSON-Backup exportieren und importieren.

## Aktuelle Funktionen

- Responsive Navigation und Dashboard
- Aufgaben anlegen, erledigen und löschen
- IdeaCloud mit Ideen speichern
- Sanfte Bewegungseinheiten mit Anleitungen
- Self-Care-Gewohnheiten
- Budget-Einträge in CHF
- Tagebuch, Notizen und Sammlungen
- Rezepte, Outfit-Ideen, Reiseideen und Medien-Merkliste
- Theme-Auswahl
- JSON-Backup exportieren/importieren
